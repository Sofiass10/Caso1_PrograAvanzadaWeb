API de Álbumes - Vinilo Tico

Catálogo de álbumes de la tienda de discos.

Método Ruta Descripción Respuesta
GET /api/Album?artista={texto} Lista los álbumes, con filtro opcional por artista 200
GET /api/Album/{Id} Consulta un álbum por su Id 200 / 404
POST /api/Album Agrega un álbum 201
PUT /api/Album/{Id} Edita un álbum 204 / 404
DELETE /api/Album/{Id} Elimina un álbum 204 / 404
